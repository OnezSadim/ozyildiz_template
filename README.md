# Vers van de Buurt - Amsterdam Grocery Store

A modern, minimalist portfolio website for a local Amsterdam grocery store built with Next.js, Tailwind CSS, and Lucide React icons.

## Design System

- **Primary Color**: Kale Green (#1A4D2E)
- **Secondary Color**: Eggplant Purple (#4C1D95)
- **Backgrounds**: White (#ffffff) and Light Stone (#fcfaf8)
- **Typography**: Inter (sans-serif)
- **Vibe**: Modern Dutch Market - Minimalist and spacious

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/` - Next.js App Router pages and layouts
- `components/` - React components (Navigation, Hero, Footer)
- `app/globals.css` - Global styles with Tailwind CSS

## Sections

1. **Hero**: Split layout with "Vers van de Buurt" headline and image placeholder
2. **Navigation**: Simple links to Producten, Over Ons, and Contact
3. **Footer**: Address, opening hours, and copyright information
